# Installation notes

This archive intentionally does not include `node_modules` or a generated lockfile.

Use Node.js 24+ and run:

```bash
npm install
npm run dev
```

WebJs is buildless and serves TypeScript directly. The official scaffold command is:

```bash
npm create webjs@latest my-app
```

For this portfolio project, the app files have already been prepared, so you only need to install dependencies and run the dev server.
